# WebView Template - Expo App

A simple Expo template app with WebView integration.

## Features

- React Native WebView integration
- Loading indicator
- JavaScript and DOM storage enabled
- Clean, minimal setup

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure your URL:
   - Open `config.js`
   - Change `webViewUrl` to your desired website

## Run the App

```bash
# Android
npm run android

# iOS
npm run ios

# Web
npm run web
```

## Customization

Edit the `webViewUrl` variable in `App.js` to load your desired website.
